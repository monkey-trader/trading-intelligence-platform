# Entwürfe

Pro UI-Vorhaben ein Ordner `<TASK-ID>-<kurzname>/` mit
- `flow.excalidraw` / `flow.png`: User-Flow und Wireframe-Varianten (auch verworfene)
- `prototype.html`: freigegebener klickbarer Prototyp (direkt im Browser öffnen, nutzt die echten Design-Tokens)

Ein Prototyp ist eine **Momentaufnahme der Freigabe** und wird nicht nachgepflegt. Quelle der Wahrheit für das
fertige Design sind `docs/design.md` und der Code. Ablauf: Skill `ui-prototyping` (ai-os).
